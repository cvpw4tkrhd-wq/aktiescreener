MINA INNEHAV
Poängsättningen är ett grovt, regelbaserat filter baserat på P/E, SMA50/200, RSI14 och volymavvikelse mot 20-dagarssnitt — inte finansiell rådgivning. Data uppdateras schemalagt via GitHub Actions, se tidsstämpel ovan. Din holdings.csv bearbetas helt i din egen webbläsare och sparas bara lokalt på den här enheten — den skickas aldrig till någon server och syns inte för andra som besöker sidan.
